## How errors are sorted

Load and send failures are classified by the engine's own message (`app/src/lib/stores.ts` `classify`): `lost connection to worker` → worker lost (Reconnect, Choose devices); `not enough memory` → out of memory (Choose devices); `no model loaded` → not loaded (Reconnect). The problem is kept in the chat store, so it survives the role going back to Idle.
