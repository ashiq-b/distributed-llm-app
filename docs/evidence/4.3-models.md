## Fit rule

`app/src/features/models/fit.ts` is the same rule as `memory_guard` in `app/src-tauri/src/roles.rs`: free memory of this device plus the chosen workers, unknown counted as 0, compared with the model's `min_free_mb`. `fit.test.ts` runs the Rust test's cases, so the hint and the load guard agree. Load is enabled only when the model is Ready, this device is not a worker or mid-load, and the model fits; otherwise it is disabled with the reason.
