# 3.3 — iOS Bonjour discovery and keep-awake

**Result: the Mac and the iPhone each listed the other automatically, with real free memory and "ok" compatibility. The iPhone dropped off the Mac's list within seconds when its Wi‑Fi went off, and came back when it returned. After the iPhone app was backgrounded and reopened, both lists recovered without a restart. The iPhone screen stayed on while it was a worker.**

## Bugs found on device and fixed

1. **Mac showed as `Unknown_1a:50:…`.** The Mac had no HostName set, so its hostname came from the router (DHCP) and was built from the network card's hardware address. The app now uses the macOS Computer Name (`SCDynamicStoreCopyComputerName`). When it has to fall back to the hostname, it skips router-made names like this and uses the hardware model instead. Covered by `name_prefers_computer_name_and_skips_router_made_hostnames`.
2. **Both lists went empty after the iPhone app had been in the background.** iOS stops Bonjour work for a suspended app, and a stopped `NetService` or `NetServiceBrowser` doesn't restart by itself. So the iPhone stopped announcing and stopped seeing the Mac's heartbeats, and each side expired the other until the app was relaunched. The plugin now recreates the advert and the browser when the app returns to the foreground (`willEnterForegroundNotification`), and also when iOS reports `didNotPublish` or `didNotSearch`.

## Design notes

- **Why a plugin:** an iOS app can't send raw multicast without Apple's multicast entitlement, which a free team can't get, so `mdns-sd` can't run on the iPhone. Bonjour through the system needs only `NSBonjourServices` and Local Network permission.
- **Why `NetService` instead of `NWListener`:** `NWListener` can only advertise a port it listens on, and llama.cpp's RPC server already owns 50052. `NetService` announces the port without opening it.
- **Same rules on both platforms:** the iPhone backend uses the same expiry rules as the Mac. Rust polls the plugin's snapshot every second; a TXT change (the `seq` heartbeat every 5 s) counts as an announcement, and a peer silent for 15 s is dropped (`registry::apply_snapshot`, tested on macOS).
- **Keep-awake:** `isIdleTimerDisabled` is on while the device is a worker or has a model loaded.
