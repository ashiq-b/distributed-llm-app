# 4.6 — UI polish pass

**Result: every screen and state was reviewed at iPhone width (390 px) and Mac width (1280 px), in dark and light, against the checklist below; what fell short was fixed. `npm test` (46), the app's `cargo test` (43) and the engine's tests pass. An About sheet shows the build and the trusted-network notice.**

## Checklist

| Check | Result |
|---|---|
| Touch targets ≥ 44 pt on the phone | Raised to 44 px: theme button, banner dismiss, role switch, small buttons, sheet and dialog close buttons (their target was the 16 px icon). Tabs, switches, composer controls already were. Desktop keeps smaller pointer targets. |
| Focus rings | Global `:focus-visible` ring in the accent. Sheets and dialogs now focus the panel when opened, not the close button, so no stray ring on every tap; the address dialog focuses its field. |
| Contrast (WCAG AA, 4.5:1) | Measured from the theme tokens. Lowest: muted text on the light ground, 5.9:1. Body text 15–17:1. Accent text 6.4–7.6:1. Accent buttons 7.4:1 (light), 7.6:1 (dark). Error text 5.5:1. |
| Motion only where it helps | Mesh lights only on real events (tokens, heartbeats, load steps); band sweep per token; one pulsing dot each for "searching" and the unopened split card; theme reveal. With Reduce Motion all of it stops; looping animations now run once instead of flickering. |
| Spacing and hierarchy | Empty mesh boxes removed (Chat with no workers, loading on one device); loading shows the model's name, not its id; Delete on Models is a real button. |

## About sheet

Opens from the distllm wordmark (both), "About" in the Mac sidebar, and a link at the bottom of Devices. Shows the app version, the pinned llama.cpp (`v1.0.0`, commit `b1b770d90d94cad9e9ea5b993bdbc383a522fb28`, from `engine/LLAMA_CPP_VERSION` via `dl_engine::llama_cpp_pin`) and the RPC protocol (`10.0.0`), and:

> Use on a network you trust. Devices talk over llama.cpp's RPC protocol, which has no password and no encryption. While a device is a worker, anyone on the same Wi‑Fi can find it and send it work, and what passes between devices can be read on the network. Use Worker only on a network you trust, such as your home or office Wi‑Fi, and switch back to Idle when you're done.
