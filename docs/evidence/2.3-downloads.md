# 2.3 — Model downloads: resumable and checksum-verified

**Result: on the iPhone, a real download survived losing the network mid-transfer, resumed from the same byte, verified, and the model then ran on the phone.**

## On the iPhone (iPhone 15, iOS app, debug build)

| Step | Observed |
|---|---|
| Download Qwen3.5 0.8B (834 MB, Q8_0) | Progress counted up |
| Wi‑Fi and mobile data turned off at **285 MB** | Error shown; model shown as "paused at 285 MB" with Resume |
| Network back on, Resume | Continued from 285 MB, not from 0 |
| End | `Qwen3.5 0.8B · Qwen · Q8_0 · 834 MB — ready` (only after the SHA-256 matched the catalog) |
| Load with no workers, chat | `Apple A16 GPU · this device · layers 0–25 · 763.78 MiB`; asked for the capital of Spain → "The capital of Spain is Madrid." — 267 tokens in 8.6 s, stopped: eos |

The single-device share (763.78 MiB, layers 0–25) is identical to the Mac's for the same model.
